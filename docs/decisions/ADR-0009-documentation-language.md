# ADR-0009: Separate public project language from learning notes

- **Status:** Accepted
- **Date:** 2026-10-11

## Context
The learner benefits from Azerbaijani explanations, while an international portfolio is easier to review when its public entry point uses English.

## Decision
Use English for README, public API documentation, code identifiers, and standard technical names. Use Azerbaijani for internal learning logs and explanations where it improves comprehension.

## Consequences
- Keep public claims precise and internationally understandable.
- Do not translate established code identifiers.
- Ensure internal learning notes do not become required for a reviewer to run the project.
